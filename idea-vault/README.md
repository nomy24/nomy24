# アイデア貯蔵庫

思いついたことを **声とキーボードでためておく**、スマートフォン向けの Web アプリです。
考えをまとめるときは、ためた内容を**そのまま生成AIに貼れる形でコピー**して渡します。

データはこの端末の中だけに残ります。サーバーもログインもありません。

## できること

| 画面 | 内容 |
| --- | --- |
| ためる | 右下のマイクで音声入力。話して間をあけるたびに、その場で1件ずつたまる（リアルタイム）。上の入力欄からキーボードでも追加できる。検索・タグ絞り込み・書きなおし（ここでも声で書き足せる）・上に固定・消す（消したあと6秒は「元に戻す」が出る）。**いま出ているメモを、依頼文つきで1タップでコピー** |
| 設定 | 音声の動き（区切りごとに保存するか、切れたらつなぎ直すか、言語）、データの移行（書き出し・移行コード・取り込み）、全消去 |

## AIに渡す

一覧の上にある「**AIに貼る用にコピー**」を押すと、**いま画面に出ているメモ**（検索やタグで絞った結果）が、
短い依頼文つきでクリップボードに入ります。あとは Claude などの入力欄に貼るだけです。

「選ぶ」で数件だけ選んでから、選択バーの「コピー」を押せば、その数件だけを渡せます。

コピーされる中身はこういう形です。依頼文が要らなければ、貼ったあとで先頭の数行を消してください。

```
次のメモは、私が思いついたことをためたものです。断片で、文章として整っていません。
ここから、目的そのものが違うアプリ案を3つ立ててください。…（依頼文）

--- メモ（3件・9/10書き出し） ---
- [9/10] #共有 職員みんなで電話メモを共有したい。引き継ぎのときに漏れる。
- [9/9] #窓口 窓口の問い合わせ内容を記録して、同じ質問の回数を集計したい。
- [9/8] 月末の定型作業を自動でリマインドしてほしい。毎回忘れる。
```

メモの本文は切り詰めません（要約すると、渡した相手が読み違えるため）。

> 以前は、端末の中だけで「アプリ案を3通り」組み立てる画面を持っていました。
> 用意した切り口の外に出られず、文脈も読めないため、生成AIに渡したほうが早いという結論で削除しました
> （`git log` に残っています）。

## 音声入力について

ブラウザの音声認識（Web Speech API）を使います。**Chrome と Safari で動きます**。
対応していないブラウザでは、マイクのボタンが押せない状態になり、文字入力だけが使えます。

- **ひと区切りごとに保存**（初期設定：オン）— 話して間をあけるたびに1件としてたまります。会議中や移動中に、思いつくままに話し続ける使い方向け
- オフにすると、「とめる」を押したときに、話した内容がまとめて1件になります
- **止まっても聞き直す**（初期設定：オン）— 端末側が勝手にマイクを切ることがあるため、自動でつなぎ直します
- 認識のまちがいは、あとからカードの「書きなおす」で直せます
- **書きなおすときも声が使えます。**「声で書き足す」を押すと、話した内容が今ある文章の次の行に足されます。元の文は消しません

初回はマイクの許可を聞かれます。許可しないと使えません。

なお、HTML ファイルをそのまま（`file://` で）開いた場合は、ブラウザがマイクを渡さないため音声入力は動きません。
`https://`（GitHub Pages）か `http://localhost`（手元で簡易サーバーを立てたとき）で開いてください。

## データの置き場所

**この端末（ブラウザ）の中だけ**に保存しています。サーバーには何も送りません。

そのため、機種変更やブラウザのデータ削除で消えます。また、同じアプリでも
**開いた場所（GitHub Pages／手元のファイル）ごとに保存先が別**になります。

## データの移行

設定画面の「データの移行」から、2通りの方法で移せます。どちらもサーバーは通りません。

### ほかの端末へ持っていく

| 方法 | 使いどころ |
| --- | --- |
| ファイルに書き出す | いちばん確実。JSON ファイルとして保存し、相手の端末で「ファイルを選ぶ」から読み込む |
| ほかのアプリに送る | iPhone などで、AirDrop・メール・チャットにそのまま渡す（対応している端末でだけボタンが出ます） |
| 移行コードを作る | 中身を圧縮して英数字の文字列にする。コピーして、移したい端末で貼り付ける。メモ60件でおよそ800文字 |

### この端末に取り込む

「ファイルを選ぶ」か「コードを貼る」で読み取ると、**取り込む前に確認画面**が出ます。

- 新しく増える件数／内容が新しくなる件数／すでに同じものがある件数
- **今のものに足す**（同じメモは二重にならず、内容は新しいほうが残ります）
- **全部を入れ替える**（今の中身は消えますが、直後に出る「元に戻す」で取り消せます）

移行コードは改行や空白が混ざっても読めます。途中で切れている場合は、その場で知らせます。

## ファイル

```
index.html              画面
app.css                 見た目
app.js                  操作（画面の組み立て・音声・コピー・書き出し）
store.js                保存（localStorage）
migrate.js              端末をまたいでデータを移すところ
sw.js                   オフラインで開くためのキャッシュ
manifest.webmanifest    ホーム画面に追加するための設定
icons/                  アイコン
scripts/make-icons.mjs  icons/*.png をつくり直すスクリプト
```

ビルドはありません。ファイルをそのまま置いています。
アイコンの絵（`icons/icon.svg`）を直したときだけ、次を実行して PNG を作り直します。

```sh
node idea-vault/scripts/make-icons.mjs
```
