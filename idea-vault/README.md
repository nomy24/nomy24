# アイデア貯蔵庫

思いついたことを **声とキーボードでためて**、たまった内容から
**アプリ案・デザイン案を3通り** 組み立てるスマートフォン向けの Web アプリです。

提案は、よいところだけを並べません。欠点、業務で長く使ったときに壊れるところ、
維持にかかる手間、そして「やめる条件」まで一緒に出します。

## できること

| 画面 | 内容 |
| --- | --- |
| ためる | 右下のマイクで音声入力。話して間をあけるたびに、その場で1件ずつたまる（リアルタイム）。上の入力欄からキーボードでも追加できる。検索・タグ絞り込み・書きなおし（**ここでも声で書き足せる**）・上に固定・消す（消したあと6秒は「元に戻す」が出る） |
| 3案 | もとにするメモ（直近20件／すべて／選んだもの／タグ）を決めて「3案をつくる」。**13通りの切り口**からメモに合うものを選び、系統が重ならない3つを出す。各案に**さわれる画面見本**・機能・デザイン案・よいところ・容赦なく言うと・3年で見た長期の話・やめどきが付く。「別の切り口で3案つくる」で、まだ出していない切り口に入れ替えられる。つくった提案は履歴に残る |
| 設定 | 音声の動き（区切りごとに保存するか、切れたらつなぎ直すか、言語）、提案のつくり方（端末の中 / AI）、書き出し・読み込み・全消去 |

## 3案の出し方

**「同じアプリの大・中・小」を3つ出しても選べません。** そこで、目的そのものが違う切り口を13通り持たせています。

| 系統 | 切り口 |
| --- | --- |
| ためる | とにかく早く書き留める／話した言葉を残す／現場で写真とセットに残す |
| 整理する | あとで確実に見つける／ためて、まとめて読む |
| 人と回す | 引き継ぎを落とさない／手順を型にして抜けを防ぐ／期限と当番を落とさない |
| 相手に対応する | 同じ質問に二度答えない |
| 機械にやらせる | 同じことを二度書かない／たまった分を機械にまとめさせる |
| 数で見る | 週に一度、数で振り返る／続いていることを絶やさない |

メモに出てくる言葉・話題・相手・件数から各切り口に点を付け、**系統・手間・画面の型が重ならないように3つ**選びます。
点が届かない切り口が混ざったときは、そのことを判定に書きます（「この切り口を必要とする話が出ていない」「20件たまってから戻ること」など）。

「別の切り口で3案つくる」を押すと、すでに出した切り口を避けて、次の3つを出します。13通りを出し切ると最初に戻ります。

## 3案の中身

1つの案につき、次のものが出ます。

- **画面の見本（さわれます）** — スマホ1画面ぶんの見本。切り口ごとに画面の形が変わります（一覧・状態ボード・下書きの確認・辞書・写真の格子・カレンダー・チェック表・ひな形・数字・日課の10種）。ためたメモが中身として入り、タブの切り替えや状態の変更が実際に動きます。見た目と操作の感じを確かめるためのもので、本物のアプリではありません
- **率直な判定** — 作るべきか、いま作るべきでないか。おすすめしない案には、はっきりそう書きます
- **3つの点** — 作りやすさ／続けやすさ／**メモとの合い方**（実際の効き目は端末の中では測れないので、測れるものだけを点にしています）
- **この案でつくるもの** — 主な機能と、ざっくりの作業量
- **デザイン案** — 画面の型、並べ方、操作の核、文字、動き、配色（実際の16進数）、画面の並び
- **よいところ**
- **容赦なく言うと** — 弱点。「作らなくてよかった」で終わる可能性も書きます
- **業務で長く使うなら（3年で見る）** — 効いてくるところ／時間とともに壊れるところ／維持にかかるもの
- **作る前にやること・やめどき** — 数えられる条件で書いた撤退ライン

最後に「そもそも作らない案」も出します。既存の道具で足りるなら、それが一番安いからです。

## 音声入力について

ブラウザの音声認識（Web Speech API）を使います。**Chrome と Safari で動きます**。
対応していないブラウザでは、マイクのボタンが押せない状態になり、文字入力だけが使えます。

- **ひと区切りごとに保存**（初期設定：オン）— 話して間をあけるたびに1件としてたまります。会議中や移動中に、思いつくままに話し続ける使い方向け
- オフにすると、「とめる」を押したときに、話した内容がまとめて1件になります
- **止まっても聞き直す**（初期設定：オン）— 端末側が勝手にマイクを切ることがあるため、自動でつなぎ直します
- 認識のまちがいは、あとからカードの「書きなおす」で直せます
- **書きなおすときも声が使えます。** 「書きなおす」の中の「声で書き足す」を押すと、話した内容が今ある文章の続き（次の行）に足されます。元の文は消しません

初回はマイクの許可を聞かれます。許可しないと使えません。

なお、HTML ファイルをそのまま（`file://` で）開いた場合は、ブラウザがマイクを渡さないため音声入力は動きません。
`https://`（GitHub Pages）か `http://localhost`（手元で簡易サーバーを立てたとき）で開いてください。

## データの置き場所

**この端末（ブラウザ）の中だけ**に保存しています。サーバーには何も送りません。ログインもありません。

そのため、機種変更やブラウザのデータ削除で消えます。また、同じアプリでも
**開いた場所（GitHub Pages／手元のファイル）ごとに保存先が別**になります。
移すには、下の「データの移行」を使ってください。

## データの移行

設定画面の「データの移行」から、2通りの方法で移せます。どちらもサーバーは通りません。

### ほかの端末へ持っていく

| 方法 | 使いどころ |
| --- | --- |
| ファイルに書き出す | いちばん確実。JSON ファイルとして保存し、相手の端末で「ファイルを選ぶ」から読み込む |
| ほかのアプリに送る | iPhone などで、AirDrop・メール・チャットにそのまま渡す（対応している端末でだけボタンが出ます） |
| 移行コードを作る | 中身を圧縮して英数字の文字列にする。コピーして、移したい端末で貼り付ける。ファイルを扱いにくい場面むけ |

「提案の履歴も一緒に持っていく」を外すと、ためたメモだけになり、コードが大幅に短くなります
（メモ60件でおよそ800文字。提案を含めると数千〜1万文字になります）。

### この端末に取り込む

「ファイルを選ぶ」か「コードを貼る」で読み取ると、**取り込む前に確認画面**が出ます。

- 新しく増える件数／内容が新しくなる件数／すでに同じものがある件数
- **今のものに足す**（同じメモは二重にならず、内容は新しいほうが残ります）
- **全部を入れ替える**（今の中身は消えますが、直後に出る「元に戻す」で取り消せます）

移行コードは改行や空白が混ざっても読めます。途中で切れている場合は、その場で知らせます。

## AI に考えさせる（任意）

初期設定では、提案は **端末の中だけ** で組み立てます（通信なし・無料）。
もっと踏み込んだ提案が欲しいときは、設定画面で「AIに考えさせる」をオンにし、
Anthropic の API キーを入れると、Claude が提案を書きます。

- キーはこの端末の `localStorage` にだけ置かれ、送り先は `api.anthropic.com` だけです
- **共用の端末では使わないでください。** キーは入力欄を空にすれば消せます
- 仕事の内容や個人情報を外部に送ってよいかは、使う前に確認してください
- 失敗したときは、端末の中でつくった提案に自動で切り替わります

## ファイル

```
index.html              画面
app.css                 見た目
app.js                  操作（画面の組み立て・音声・書き出し）
store.js                保存（localStorage）
propose.js              3案をつくるところ（端末の中で完結）
mockup.js               案の画面見本を組み立てるところ
migrate.js              端末をまたいでデータを移すところ
ai.js                   AIに考えさせるとき（任意）
sw.js                   オフラインで開くためのキャッシュ
manifest.webmanifest    ホーム画面に追加するための設定
icons/                  アイコン
scripts/make-icons.mjs  icons/*.png をつくり直すスクリプト
```

ビルドはありません。ファイルをそのまま置いています。
アイコンの絵（`icons/icon.svg`）を直したときだけ、次を実行して PNG を作り直します。

```sh
node idea-vault/scripts/make-icons.mjs
```
