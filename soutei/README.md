# デイサービス送迎表

車両8台（5人乗り6台・7人乗り2台）の送迎ルートを、往路・復路それぞれA4横1枚に収める運行表。
`index.html` の1ファイルで完結（外部CSS・JS・フォントなし）。ブラウザで開いてそのまま印刷できる。

## レイアウトの考え方

送迎表は「時間割」ではなく「車ごとの巡回順」なので、時刻をタテ軸に取ったマトリクスではなく
**車両カード×8を2列に並べる**構成にした。

各カードは左右2カラム。

- **左**：号車番号／乗車定員／運転手／ナンバー、そして定員ピップ（`■`＝乗車・`□`＝空席）
- **右**：ルート順の行リスト（`順番 / 時刻 / 利用者名 / 地区・住所 / 記号`）と、事業所着の時刻

要件との対応は次のとおり。

| 要件 | 表現 |
| --- | --- |
| 利用者名 | 各行の主要素。行内で最も大きい文字 |
| 送迎時間 | 各行の先頭に配置。`tabular-nums` で桁を揃え、上から下へ時系列に読める |
| ルート順 | 丸数字を縦線でつないだ経路線。順番＝行順そのもの |

## 設計上の判断

- **行数＝定員**。5人乗りは4行、7人乗りは6行を必ず描画し、埋まっていない席は空行として残る。
  空席が「見えないもの」ではなく「見えるもの」になるので、当日の追加受入の余地が一目でわかる。
  定員を超えて名前を入れると、カードのピップと合計欄が警告色になり `⚠ 定員超過` が出る。
- **往路と復路を色相で分ける**。往路＝藍、復路＝柿渋。画面ではタブで切り替え、印刷では
  それぞれ別ページになるので、刷り上がった紙を取り違えにくい。
- **記号は3つに絞る**。`車`＝車椅子、`介`＝乗降介助、`玄`＝玄関先まで。
  行ごとにクリックで切り替えられ、印刷しても薄い枠が残るので現場で手書き追記もできる。
- **見出しは明朝、データはゴシック**。帳票としての体裁を保ちつつ、読み取る情報はゴシックで拾いやすくする。
  日本語ウェブフォントは重いので、OS標準フォントのスタックで指定している。

## 使い方

- 氏名・時刻・地区・事業所着の時刻はクリックしてその場で書き換えられる（貼り付けは書式を落として挿入）。
- 「印刷」で往路1枚・復路1枚のA4横として出力される。ブラウザの印刷設定で「背景のグラフィック」を有効にすると、
  号車欄の地色とヘッダの帯が印刷される。
- 記入内容はページを閉じると消える。日々の記録として残す運用なら、印刷またはPDF保存を前提にしてほしい。

## 車両・利用者データの差し替え

`index.html` 末尾のスクリプトにある2つの定数を書き換えるだけでよい。

```js
const FLEET = [
  { no: 1, seats: 5, plate: "品川 500 あ 12-34", driver: "佐藤 健一" },
  // seats は乗車定員ではなく車検証上の乗車人数。定員は seats - 1（運転手を除く）で自動計算される
];

const PLAN = {
  out: { title: "往路", sub: "お迎え", label: "自宅 → 事業所", runs: { 1: { arrive: "09:35", stops: [ … ] } } },
  ret: { … }
};
```

`runs` のキーは号車番号。`stops` は `{ t: "08:35", who: "田中 ハル", area: "中央町 3丁目", tags: ["介"] }` の配列で、
並び順がそのままルート順になる。台数を増減した場合も `FLEET` の要素数に追従してカードが生成される。

収録している利用者名・住所・車両番号はすべて動作確認用の架空データ。
