# 案（検討のあと）

**ここにあるのは、いまのアプリを決めるまでに見くらべた案です。**
アプリ本体（`../index.html`）はこのフォルダを一切参照していないので、
消してもアプリは動きます。あとで「なぜこの形にしたか」を辿るために残してあります。

どれも1ファイルで開けます。ブラウザにそのまま放り込んでください。

## 紙の見本

`*_プレビュー.html` は原寸で見て**そのまま刷れる**もの。
`*_見本.pdf` はそれを PDF にしたもの。

- 送迎表 … `送迎表案1_*`、`送迎表_4便_見本.pdf`
- 業務日誌 … `業務日誌案1_*`
- 電話連絡表 … `電話連絡表案1_*`、`電話連絡表案3_*`
- 電話帳 … `電話帳案1_見本.pdf`、`電話帳案1改_*`、`電話帳案2_見本.pdf`、`電話帳案3_見本.pdf`
