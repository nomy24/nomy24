# 送迎表を事業所で共有する（はじめかた）

事業所の PC を1台「サーバー役」にして、送迎表のデータをその PC の中に置く。
同じネットワークにつながっている他の PC・タブレットから、同じ表を開いて共有できる。

**データはこの PC の中だけに残る。**インターネットには出ない。

---

## 用意するもの

- **サーバー役にする PC 1台**（事務所に置きっぱなしにできるもの。Windows で構わない）
- 同じネットワーク（同じ Wi-Fi・同じ LAN）につながった、使いたい PC やタブレット

インターネット回線は**使わない**。事業所の中のネットワークだけで動く。

---

## 手順1　Node.js を入れる（サーバー役の PC だけ・初回のみ）

1. <https://nodejs.org/ja/> を開く
2. **「LTS」** と書かれたほうのボタンを押してダウンロード
3. ダウンロードしたファイルを開き、**「次へ」を押していくだけ**でよい（設定を変える必要はない）

これは送迎表を動かすための土台で、1回入れれば以後は不要。

## 手順2　フォルダを作ってファイルを置く

サーバー役の PC に、たとえば次のフォルダを作る。

```
C:\送迎表\
```

その中に3つのファイルを入れる。

| ファイル | 中身 |
| --- | --- |
| `index.html` | 送迎表そのもの |
| `soutei-server.js` | 保存サーバー |
| `送迎表サーバー起動.bat` | 起動用 |

## 手順3　起動する

`送迎表サーバー起動.bat` を**ダブルクリック**する。黒い画面が出て、次のように表示される。

```
===========================================
 デイサービス送迎表　保存サーバー　起動しました
===========================================

 この PC からは       : http://localhost:8080/
 他の PC・タブレットは : http://192.168.1.24:8080/

 データの置き場所      : C:\送迎表\data
 保存済みの日          : まだありません

-------------------------------------------
 合言葉 : KRTM-8H4P-N2XW
-------------------------------------------
 初めての起動なので、合言葉を新しく作りました。
```

**「他の PC・タブレットは」の行のアドレスと、「合言葉」を控えておく。**
（どちらも事業所ごとに違う）

初回だけ Windows が「このアプリの通信を許可しますか」と聞いてくることがある。
**「プライベート ネットワーク」にチェックを入れて許可**する。これを断ると他の PC から開けない。

> この黒い画面は**開いたままにしておく。**閉じるとサーバーが止まる。
> 最小化しておけばよい。

## 手順4　他の PC・タブレットから開く

ブラウザのアドレス欄に、手順3で控えたアドレスを入れる。

```
http://192.168.1.24:8080/
```

**初めての端末では「合言葉を入れてください」と聞かれる。**
手順3で控えた合言葉（`KRTM-8H4P-N2XW` の形）をそのまま入れて「つなぐ」を押す。
大文字小文字はそのまま。**その端末では次から聞かれない。**

送迎表が開いたら、**日付の右に「サーバー保存　共有中」**と出ていることを確かめる。
これが出ていれば、その端末の入力は他の端末にも反映される。

よく使う端末は**ブックマーク**しておくとよい。

### 合言葉について

**合言葉を知らない人は、名簿を見ることも書き換えることもできない。**
同じ Wi-Fi につながっただけでは中身に触れられないので、
来客用の回線と分けきれていない事業所でも、ひとまず安心して使える。

- 控えは `data\合言葉.txt` にある。忘れたらここを見る
- **職員以外に教えない。**紙に書いて貼るなら、来客の目に入らない場所に
- 変えたいときは `data\合言葉.txt` を消してサーバーを立ち上げ直す。
  新しい合言葉が作られるので、各端末で入れ直す
- 「手元だけで使う」を押せば合言葉なしでも送迎表は使える。
  ただし**その端末の中だけの保存**になり、他の端末とは共有されない

---

## 毎日の使い方

- 朝、サーバー役の PC を起動したら `送迎表サーバー起動.bat` をダブルクリックする。
- あとは今までどおり使うだけ。保存の操作は要らない。
- 帰りに PC を落とせばサーバーも止まる。

### 毎回ダブルクリックするのが面倒なとき

Windows の**スタートアップ**に入れておくと、PC を起動したときに自動で立ち上がる。

1. キーボードの `Windows` + `R` を押す
2. `shell:startup` と入力して Enter
3. 開いたフォルダに、`送迎表サーバー起動.bat` の**ショートカット**を入れる

---

## 送迎中のタブレットについて

**車の中（事業所の外）では、サーバーにはつながらない。**事業所の Wi-Fi の外だから。

ただし**入力はできる。**送迎表は「まず手元に保存して、あとから送る」作りにしてある。

1. 事業所を出る前に、タブレットで送迎表を開いておく（この時点で最新が入る）
2. 車の中で実績などを書く → **その場では手元に保存される**（表示は「つながりません（手元に保存しています）」に変わる）
3. 事業所に戻って Wi-Fi につながると、**自動でサーバーに送られる**

タブレットのブラウザを閉じてしまっても、書いたものは残る。次に開いたときに送られる。

---

## 新しい版に入れ替える

送迎表やサーバーを新しくしたときの手順。**差し替えるのはファイルだけで、
`data` フォルダには手を触れない。**ここに保存した送迎表と合言葉が入っている。

### 手順1　サーバーを止める

黒い画面で `Ctrl` + `C` を押す。または画面を閉じる。

> 止めずに差し替えると、書きかけが中途半端に残ることがある。**必ず先に止める。**

### 手順2　いまのフォルダを丸ごと控える

`C:\送迎表` を右クリック →「コピー」→ デスクトップなどに「貼り付け」。
`送迎表 - コピー` ができればよい。**戻したくなったらこれを使う。**

### 手順3　2つのファイルを上書きする

`C:\送迎表` に、新しい版の次の2つを入れて**上書き**する。

| ファイル | 何が変わるか |
| --- | --- |
| `index.html` | 送迎表そのもの |
| `soutei-server.js` | 保存サーバー |

「置き換えますか」と聞かれたら**「ファイルを置き換える」**を選ぶ。

`送迎表サーバー起動.bat` は変わらないので、そのままでよい。

> **`data` フォルダは消さない・触らない。**
> 中に保存した日ぶんの送迎表と、合言葉が入っている。
> 間違えて消すと、その日までの記録が無くなる。

### 手順4　起動して確かめる

`送迎表サーバー起動.bat` をダブルクリックする。黒い画面に

- 「他の PC・タブレットは」のアドレス
- **合言葉**（`data\合言葉.txt` が残っていれば今までと同じもの）

が出れば成功。

### 手順5　各端末で開き直す

タブレットや他の PC で送迎表を開いている場合は、**画面を更新する**
（`F5`、またはブラウザの再読み込み。タブレットは画面を下に引っ張る）。

日付の右が「**サーバー保存　共有中**」になっていれば入れ替え完了。

初めて合言葉を使う版に上げたときは、端末ごとに1度だけ聞かれる。

### 元に戻したいとき

手順2で控えたフォルダの `index.html` と `soutei-server.js` を書き戻して、
起動し直す。`data` はそのままでよい。

## 困ったときは

**「サーバー保存　共有中」と出ない**

そのアドレスでサーバーにつながっていない。手順3の黒い画面が出ているか、
アドレスが合っているかを確かめる。ファイルを直接ダブルクリックして開いた場合
（アドレスが `file:///...` になっている場合）は、その端末の中だけの保存になる。

**他の PC から開けない**

- サーバー役の PC の黒い画面が閉じていないか
- 手順3の「許可しますか」を断っていないか
  （Windows の「ファイアウォールとネットワーク保護」→「アプリを許可」から Node.js を許可し直せる）
- 同じ Wi-Fi につながっているか（来客用 Wi-Fi は別のネットワークのことがある）

**「合言葉が要ります」と出たまま進めない**

日付の右が「手元に保存しています（合言葉が要ります）」のままなら、合言葉が合っていない。
サーバーの黒い画面か `data\合言葉.txt` で確かめて、入れ直す。
`0` と `O`、`1` と `I` は合言葉に使っていないので、紛れることはない。

**「合言葉の間違いが続いています」と出た**

続けて10回間違えると、その端末からは1分だけ受け付けなくなる。
総当たりで当てられないようにするためのもの。1分待てば元に戻る。

**「この住所では使えません」と出た**

サーバーが知らない名前で呼ばれている。手順3の黒い画面に出ているアドレスで開き直す。
社内の別名（`soutei.local` など）で開きたいときは、起動のときにその名前を教える。

```
set SOUTEI_HOSTS=soutei.local
node soutei-server.js
```

**「この送迎表は事業所の中からだけ使えます」と出た**

事業所の外のネットワークから開こうとしている。名簿を外に出さないための決まり。

**「ポート 8080 は他で使われています」と出た**

黒い画面で次のように打つと、別の番号で起動できる。その場合、開くアドレスも `:8081` に変わる。

```
node soutei-server.js 8081
```

**「他の端末での変更を取り込みました」と出た**

同じ日の表を他の人が先に直していたということ。
画面はその人の内容に合わせてある。自分の直前の変更を戻したいときは **「一つ戻る」**を押す。

---

## データの控え（バックアップ）

データは次のフォルダに、1日1ファイルで入っている。

```
C:\送迎表\data\
```

`day.2026-07-27.json` のような名前のファイル。`users.json`（利用者マスタ）などもここにある。

**このフォルダを丸ごとコピーしておけば控えになる。**
月に一度、USB メモリなどにコピーしておくとよい。
戻すときは、コピーしたファイルを同じフォルダに書き戻してサーバーを起動し直す。

利用者の氏名と住所が入っているので、控えの置き場所は事業所の規定に従って管理する。
