# 送迎表（8台運用）

送迎車両8台の「今どこを走っているか」を朝礼・出発前チェックでひと目で確認できる、職員向けの運行ボードです。

## デザインの考え方

このリポジトリには既に2つの配色体系があります（「南区インフォ」のあじさい色、「職員Todo」のティール×オレンジ）。送迎表は3つ目の系統として、送迎という題材そのもの — 道路と停留所 — を画面の構造に落とし込みました。

- **紙とアスファルト**：温かみのある紙色の背景に、車両バッジは道路のアスファルト色。方向指示器の橙・信号の緑・注意の朱で状態を表します。
- **運行ライン（本設計の軸）**：各車両の行に、出発から到着までを1本の道として描き、経由する利用者宅を停留所のドットで並べます。「走行中」の車両には道の上に現在地マーカーが乗ります。実際の送迎ルートをそのままUIの構造にしています。
- **午前／午後の切り替え**：お迎え（午前）とお送り（午後）をワンタップで切り替え。稼働台数・到着済・利用者数・要確認件数を控えめなKPIとして常時表示します。
- **印刷対応**：「印刷用に表示」から、車内に持ち込む紙の運行表としても出力できます。

## できること

| 機能 | 内容 |
| --- | --- |
| 運行ボード | 8台分の運転士・添乗・乗車人数・経路・状態（待機／走行中／到着済／要確認）を一覧表示 |
| 午前・午後の切り替え | お迎え／お送りのルートをワンタップで切り替え |
| 概況表示 | 稼働台数・到着済台数・利用者数・要確認件数を常時表示 |
| 印刷 | 車内携帯用に印刷しやすいレイアウトへ切り替え |
| アクセシビリティ | フォーカスリング、4.5:1以上のコントラスト、44px以上のタップ領域、`prefers-reduced-motion`対応 |

## データについて

`app.js` 内のスケジュールはデザイン確認用のサンプルです。**実際の利用者名・住所などの個人情報は含まれていません**（A様・B様のような記号と、地区名のみのダミーです）。実運用では、この構造を保ったまま実際の運行データに差し替えてください。

## 公開する

GitHub Pages を有効にすると、そのまま公開できます。

1. リポジトリの **Settings › Pages** を開く
2. **Source** で `Deploy from a branch` を選び、ブランチ `main` / フォルダ `/ (root)` を指定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/shuttle-schedule/` で開けます
